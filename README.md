# Future Builders Public School — Windows download

Download **FutureBuildersSchool-win-x64.zip** from this branch. Open the ZIP file page and click **Download raw file** (the download arrow).

1. Use a Windows 64-bit computer.
2. Right-click the downloaded ZIP and choose **Extract All**.
3. Open the extracted **FutureBuildersSchool** folder.
4. Run **FBPS.WinForms.exe**. Keep all extracted files together.

This is a self-contained build: Visual Studio and a separate .NET installation are not required.

Release candidate: 144 automated tests passed. Clean-Windows, GUI restore/restart and physical printer acceptance remain pending. Test with sample data before live school use. The user manual is in the extracted docs/USER-MANUAL.md file.

The SHA-256 file lets you verify the downloaded archive. No student database is included.
